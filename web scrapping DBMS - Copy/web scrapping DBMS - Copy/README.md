# Professional Profile Aggregator

## Description

Professional Profile Aggregator is a web application that accepts one professional profile URL (e.g., GitHub) and gathers publicly available professional information from supported platforms using official APIs where available. It stores the collected data in a MySQL database and provides analytics through a dashboard.

## Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- GitHub REST API
- Stack Exchange API
